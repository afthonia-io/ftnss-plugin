# FTNSS

## Claude (web and desktop)

1. Add FTNSS in one of two ways:
   - **Connector:** open Customize › Connectors, select **Add** › **Add custom connector**, enter
     the name `FTNSS` and the URL `https://mcp.afthonia.io/mcp`, then select **Add**.
   - **Plugin:** open Customize › Plugins and add FTNSS.
2. Select **Connect** on FTNSS. For the plugin, it is on the plugin's **Connectors** tab.
3. On your phone, open FTNSS › Settings › Assistants and tap **Connect**, **Next**, then
   **Get code**.
4. Type the code on the FTNSS page that opens, then select **Connect**.

## Claude Code

Signed in with your Claude account, Claude Code already has FTNSS once you connect it in Claude.

To add it to Claude Code on its own:

1. Run `claude mcp add --transport http --scope user ftnss https://mcp.afthonia.io/mcp`.
2. Run `claude mcp login ftnss`.
3. On your phone, open FTNSS › Settings › Assistants and tap **Connect**, **Next**, then
   **Get code**.
4. Type the code on the FTNSS page that opens, then select **Connect**.

## ChatGPT

1. Select **Plugins** in the sidebar, then select FTNSS and install it.
2. Select **Connect**.
3. On your phone, open FTNSS › Settings › Assistants and tap **Connect**, **Next**, then
   **Get code**.
4. Type the code on the FTNSS page that opens, then select **Connect**.
